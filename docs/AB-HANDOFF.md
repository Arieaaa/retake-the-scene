## B 首批接口交接

浏览器仅接收 `PlayerView`；生产模式不得包含完整剧本与未来结局。A 的作者预演明确使用本机存档与预写对白，不代表服务器持久化、权限隔离或 Cloud Agents 实测。

- 固定动作请求：`{"requestId":"turn-7","expectedRevision":1,"stage":2,"actionId":"private_preview","params":{"target":"writer"}}`。
- 私下看片不要求第一拍先预览，授权由编剧本人、当前分支确认；公开递麦不自动授权。
- 等待响应：`{"requestId":"turn-7","status":"pending","pollUrl":"/api/runs/r1/branches/b1/turns/turn-7"}`。
- 错误必须给 `code`、`message`、`retryable`，状态码遵循工程稿 4.3。
- 请求体与视图类型在 `shared/contracts/index.ts`；字段调整请同步成功、等待与失败响应样例。
- 实际 Sites Function 使用 `/functions/v1/app`，工程稿的 `/api/...` 为业务子路由；B 确认映射后配置前端，浏览器不能携带云服务密钥。
- 恢复失败不再因404自动创建新局。已知剧目的错误页提供“另开一局”，显式进入 `/#/new/:episodeId` 并只调用 create；创建失败重试沿用同一 `createKey`，成功前保留原进度位置，不发删除请求。创建期间回片单后，迟到响应不改变路由或本机进度；没有剧目信息的陌生存档链接只提供回片单，不推测剧目。B 仍须保证 create 幂等及旧局实际保留。
- 倒带失败立即退出弹窗展示错误，保留原 `checkpointId`、`forkKey` 供“重试原操作”，未收敛前禁止提交不同动作。回合202/409的后续读取、手动重试、预写、倒带与分支对照均校验路由代次；切页后的成功、错误和加载结束回调不得覆盖新页或进度。这是前端保护，不取消已在服务器提交的写入。

- 分享自动复制失败时保留只含剧目开场的只读输入框，可键盘聚焦、全选和手动复制；不会四秒后消失，离开当前路由会清除，迟到的复制成功/失败不污染新页。封面缺少Canvas、图像解码或PNG编码失败时保留原舞台与结局，并持续显示截图指引；生成期间防重复点击。下载回调只表示已请求保存，不保证移动浏览器已经落盘。这些操作不写入游戏存档。
