## B 首批接口交接

浏览器仅接收 `PlayerView`；生产模式不得包含完整剧本与未来结局。A 的作者预演明确使用本机存档与预写对白，不代表服务器持久化、权限隔离或 Cloud Agents 实测。

- 固定动作请求：`{"requestId":"turn-7","expectedRevision":1,"stage":2,"actionId":"private_preview","params":{"target":"writer"}}`。
- 私下看片不要求第一拍先预览，授权由编剧本人、当前分支确认；公开递麦不自动授权。
- 等待响应：`{"requestId":"turn-7","status":"pending","pollUrl":"/api/runs/r1/branches/b1/turns/turn-7"}`。
- 错误必须给 `code`、`message`、`retryable`，状态码遵循工程稿 4.3。
- 请求体与视图类型在 `shared/contracts/index.ts`；字段调整请同步成功、等待与失败响应样例。
- 实际 Sites Function 使用 `/functions/v1/app`，工程稿的 `/api/...` 为业务子路由；B 确认映射后配置前端，浏览器不能携带云服务密钥。

## 舞台投影与联调约定

前端只读当前视图，不能从完整剧包推断状态。B 复核契约时，请确认以下 `presentation` 字段及实际响应样例：

| 舞台 | 消费的当前状态 | 来源边界 |
|---|---|---|
| 婚礼 | `screen`（waiting/photos/intro/original/updated_credits）、`creditsUpdated`、`missing_credit`、`micHolder`、`handoverGreen` | 控台私看与公开屏幕分离；更新署名不能只凭历史线索或前端勾选 |
| 职场 | `call`、`transfer_log`、`minutesUpdated`；已到达的 ending 和 `scene.prop` | 来电对象核实前不显示人工转接；纪要与书面交接按实际结局呈现 |
| 网恋 | `activeWindow`（both/soda）、`draftSent`；按 soda/coach 精确分组的 `visibleEvents` | 历史和日期仅在事件或已获物证出现后展示；停止的窗口不制造新回复；原稿发出后不再标为未发送 |
| 猫 | `hissCount`、`lastGesture`、`position`、`sample`、`binding`、`armed`、`coverComment`、`duetTitle`；玩家已录发言事件 | 波形不冒充麦克风录音；未匹配显示重绑；真实姿态、发言与静默被保留 |
| 扣1 | `replyTarget`、可见父消息、当前 stage、已到达 ending | 未加载完整版不开放后续帧；切帧不耗回合；正文不可改写；挡拆只是末镜交互 |

优先联调婚礼：create → preview_tail → private_preview（固定 turn-7 样例）→ lend_laptop → 在私看前 fork。B 回填实际 Cookie 所有者检查、同一 requestId 重试结果和新分支同意状态；不得用本地样例代替。接口样例位于 `fixtures/public/api-examples.json`，固定 UI 样例仅供人工比较，不代表服务端实测。
