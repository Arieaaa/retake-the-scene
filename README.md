# 这集我来演 · Retake the Scene

一款为 **2026 Qoder 高校创造力大赛 · LifeHack** 设计的原创互动短剧游戏。玩家从片单选一部戏，穿进配角，在关键时刻接管大屏、发一条消息，或亲自面对那只一定会冲你哈气的圆头耄耋。演完可以倒带，看看同一句话说给不同的人听，事情会怎样变化。

**当前进度**为 A 本地可玩预演与 B 接口交接阶段。五集作者剧包、前端舞台、等待与恢复、倒带和封面已实现，双模式构建、62项单测及69项浏览器检查通过，含五集全程Tab/Enter通关；真实云角色与托管存档尚未接入，公开版本抽检和线上盲玩仍待完成。仓库保留完整设计、双人实施计划及原始 15 条结局验收样例。可试玩的 Qoder Sites 地址将在公开版本通过匿名访问验证后补充。

## 本地开发与 A/B 联调

```sh
npm ci
npm run dev
npm test
npm run build
npm run build:site
npx playwright install chromium
npm run test:e2e
# 可选：使用已安装的 Chrome，仍为独立测试上下文
PLAYWRIGHT_CHANNEL=chrome npm run test:e2e
# 可选：将本机浏览器证据保存到 docs/evidence/
PLAYWRIGHT_CHANNEL=chrome CAPTURE_EVIDENCE=1 npm run test:e2e
```

默认运行 **编剧预写 / 本机存档** 版本；这不是在线 Agent 或云端持久化验证。A/B 状态预览为 `/#/preview/ready`、`pending`、`consent`、`ended`、`rewind`；这些固定视图不写入本机存档。

已知剧目的存档恢复失败时，可以显式“另开一局”；不会自动替换或删除旧存档，只有创建成功才更新上次游玩位置。创建响应丢失后，重试沿用同一 `createKey`；倒带失败会退出弹窗并保留检查点与 `forkKey` 供原操作重试。切页后，创建、回合续查、重试、预写、倒带和分支对照的迟到响应不会覆盖新页面与游玩位置。

动作提交后立即显示原动作、收件对象和已确认台词，并明确“尚未收到回执”；这不是已发生事件或角色运行证明。网络失败保留原提交供重试，收到200/202后再转为对应视图，不提前开放预写按钮。

对白区按提交顺序保留本分支视图提供的全部可见事件，不再截掉早期记录。新回合默认定位最新一条，可滚动或用Tab、Home、End回看；已获物证在可操作、等待和结局三种状态均可打开。查看和回放不提交新动作，也不补取角色秘密。

剪贴板不可用或权限拒绝时，分享链接留在可聚焦、可全选的只读输入框中，不随提示倒计时消失。封面生成失败保留原舞台和结局及持续截图指引；已触发下载也不宣称文件已经落盘，未出现下载时仍可截图。两项操作均不推进剧情或更改存档。

B 接入同源 Function API 后以 `npm run build:site` 构建 `dist-site/` 线上前端；该命令同时检查产物不含完整作者剧包、引擎和固定预览。E2E 会启动本机预演与站点构建预览；站点接口用明确标记的模拟响应验证客户端行为，不代表真实后台通过。浏览器调用 `/functions/v1/app/api/...`，不携带服务端密钥；站点模式错误不会自动切换为作者预演。实际响应契约、分工进度和阻塞见 [A/B 交流文档](./docs/AB-HANDOFF.md)，投稿材料见 [作品帖草稿](./docs/A-SUBMISSION-DRAFT.md)。

B 提供候选地址后，先在终端设置并导出 `RETAKE_LIVE_URL`（站点根地址，不含账号、查询参数或 hash），再执行独立真实站点入口：

```sh
PLAYWRIGHT_CHANNEL=chrome npm run test:live -- --project=preflight
# 仅在明确允许创建真实测试局及可能的角色计费后执行
RETAKE_LIVE_ALLOW_WRITES=1 PLAYWRIGHT_CHANNEL=chrome npm run test:live
```

只读门禁检查公开页面、在线模式与目录 API；通过后才执行五集360px静音键盘路径、刷新、分享新访客开场和婚礼授权前倒带。完整检查会创建至少10个测试局及1个分支，不自动删除旧记录。它不启动本机服务、不拦截或模拟响应；缺少地址或写入许可直接报错。报告写到被 Git 忽略的 `playwright-live-report/`，关闭请求追踪，观察附件不含 Cookie、存档ID或对白正文；只统计来源，不把 `live` 标签当作云执行证明。

**当前真实站点验收未完成。** 仅确认6项检查可被发现、缺少地址/许可会拒绝、作者预演会被门禁拦截；完整成功路径仍待 B 的真实候选地址。这6项未计入本机69项通过记录，也不能替代真实双角色、并发原子写、线上盲玩与发布证据。

`src/` 为 A 前端与两个传输适配器，`shared/contracts/` 为待 B 复核的契约 v1，`content/episodes/` 与 `fixtures/` 为作者剧包及本地预演，`public/art/` 与 `public/sound/` 为原创素材，`tests/` 保存原始 15 路径、状态与界面验证。海报可用 `node scripts/export-art.mjs` 再生；哈气可用 `python3 scripts/create-sound.py` 再生。
